## What I work on

- **Frontend:** React and Next.js interfaces, responsive layouts, reusable components, and state management.
- **Backend:** Node.js, Express, Python, Flask, databases, and API integrations.
- **Interaction:** GSAP and Framer Motion animations, with interactive 3D touches using Three.js and React Three Fiber in my portfolio.
- **Applied AI:** I co-developed a Flask application that uses the OpenAI API to generate resumes and other structured documents.
- **Currently exploring:** Computer vision, OpenCV, and PyTorch.

I care about clear navigation, practical software, and a button that feels right. A little fun belongs in there too.
